## Issue

The original system had creator discovery and scraping functionality but was not structured as a native Hermes Agent Plugin. It also relied on `input_channels.csv` as part of the workflow, which created uncertainty about which dataset was the authoritative creator database. Additionally, modifying the Master CRM without a recoverable backup posed a data-loss risk.

## Proposed Solution

Redesigned the system around the Master CRM as the single source of truth.

Discovery workflow:
```
Hermes Web Search
       ↓
Creator Discovery
       ↓
Duplicate Check against Master CRM
       ↓
Scrape / Validate
       ↓
Backup Master CRM
       ↓
Safe CRM Merge
       ↓
Master CRM
```

Existing creator workflow:
```
Master CRM
    ↓
Select creators
    ↓
Backup
    ↓
Scrape
    ↓
Validate
    ↓
Safe Merge
    ↓
Updated Master CRM
```

The existing `input_channels.csv` is no longer an active dependency and can be archived or removed later after further verification.
